# 스킬 후보 리스트 — 개인기/특수 동작으로 분리할 것들

작성일: 2026-09-04 | 성격: 조사/기획 리스트 (구현 안 함)
방침: 팀 전술·기본 룰은 시뮬 코어에, **선수 개인기는 "스킬"로 분리**해서
나중에 선수별로 보유/발동하게 한다. 스킬 = 트리거 조건 + 발동 확률 + 효과.

| 패스 페이크 | (미구현) 레인 점퍼를 한쪽으로 낚고 반대로 패스 | 인터셉트 회피 스킬 |

## 도입 시 설계 메모

- 스킬은 **포지션 프로파일과 별개 테이블**: `Skill { trigger, procChance, cooldown, effect }`
- 발동은 기존 상태 머신에 상태 추가가 아니라 **기존 상태의 파라미터 오버라이드**가 우선 (예: 덩크 = 레이업 windup의 성공률/블락 무효 변형)
- 시각화: 발동 시 발밑 라벨 + 이펙트 (스킬명 팝업)
- 밸런스: 스킬마다 `tool/balance_report.dart`에 발동 횟수 카운터 추가해 측정

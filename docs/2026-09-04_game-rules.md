# 경기 시뮬 룰북 — 현재 적용된 규칙 전체 정리

작성일: 2026-09-04 | 기준 코드: `lib/sim/match_sim.dart` (커밋 bfb248a)
수치는 전부 `MatchSim` 상수/`PositionProfile` 테이블에 있다. 여기 적힌 값이 코드와 다르면 코드가 정답.

## 0. 기반 구조

- **로직/렌더 분리**: 시뮬은 순수 Dart, 10Hz 고정 틱 + 시드 RNG (같은 시드 = 같은 경기). Flame은 틱 사이를 보간 재생만.
- **코트**: FIBA 28×15m, 1타일 = 1m. 3점 라인 반경 6.75m, 림 높이 3.05m.
- **팀당 5명**, id % 5 로 포지션 고정: PG/SG/SF/PF/C.

## 1. 이동

| 항목 | 값 |
|---|---|
| 기본 이동속도 | 2.8 m/s |
| 볼 소유(드리블) | ×0.8 (2.24 m/s) |
| 드라이브 | ×1.1 (3.08 m/s) |
| 같은 팀 최소 간격 | 1.1m (밀어냄) |
| 상대 팀 몸 충돌 | 0.55m — 통과 불가. 컷/리바운드 진입이 자연 스크린이 됨 |

## 2. 선수 상태 머신

`드리블 / 드라이빙 / 슛(윈드업 0.5초, 레이업 0.3초) / 페이크(0.4초) / 리시브 / 컷 / 볼추적 / 이동 / 수비 / 블락(1.0초) / 리바운드 점프(0.5초) / 박치기(0.35초) / 대기` — 시한부 상태 중엔 원칙적으로 제자리(레이업 윈드업만 림으로 활공). 발밑 라벨로 전 상태 표시.

## 3. 볼 핸들러 판단 (매 틱, 우선순위 순)

1. **인바운더면**: 0.3초 후 지정 리시버에게 인바운드 패스 (샷클락 리셋)
2. **샷클락 ≤ 0.8초**: 강제 슈팅 모션
3. **드라이빙 중**: 림 2.3m 도달 시 레이업, 아니면 계속 질주
4. **HP 1 필사 슛**: 림 5.5m 이내이거나 (샷클락<5초 & 사거리 안)이면 던짐
5. **레이업**: 림 2.3m 안에서 틱당 `layupChance`(포지션별 0.3~0.45)
6. **드라이브 시작**: 3점 라인 안 & 레이업 밖에서 틱당 9%
7. **드라이브&킥**: 1.8m 안에 수비 2명 이상 → 30% 킥아웃 (minHold 충족 시)
8. **슛 셀렉션**: 사거리 7.4m & 포지션 최대 거리 안에서
   - 오픈(수비 1.2m 밖): 틱당 45% × shootMul × (3점이면 ×0.4)
   - 세미오픈(0.8m 밖): 10% × 같은 배율
   - 밀착(1.5m 안) & 페이크 쿨탐 끝: 15% **슈팅 페이크**
9. **패스** (잡은 뒤 0.6초 경과 필요):
   - 오픈 동료(수비 2.2m 밖 + 사거리 안) 존재 → 30% 피드
   - 압박(1.0m 안) → 30% × passMul × HP긴박도(1 + 잃은HP×0.8), 최대 95%
   - 평시 → 3% × 같은 배율

## 4. 패스 규칙

- **대상 선정 점수** = 오픈도 − 골대거리×0.15 − 패스거리×0.12 + 보너스
  - 보너스: 백코트에서 PG(볼운반) +3 / 골밑 5m 안 오픈 빅맨(포스트 엔트리) +1.2 / 컷 중인 동료(백도어) +1.5 / 빅맨 운반 중 가드 아웃렛 +2
- **필터**: 직전 패서에게 즉시 리턴 금지(핑퐁 방지) / 레인 중간(t>0.15)에 수비 몸(0.55m) 걸리면 제외 / 오픈도 < 0.75 + 0.11×거리 면 제외 (아웃렛은 ×0.8 완화)
- **리드 패스**: 리시버의 수비 반대쪽으로 1.2m 리드해서 던짐
- **로브**: 빅맨(9m 밖 운반) → 가드 아웃렛은 높은 궤적(arc 1.2)
- **조기 캐치**: 비행 중 공이 리시버 0.8m 안(z<2.2)에 오면 즉시 캐치
- **캐치 실패**: 도착점에서 리시버가 1.2m 밖이면 루즈볼

## 5. 패스 인터셉트 (수비)

- 공이 수비수 몸 0.45m 안에 겹치면 **50% 스틸** (수비수당 비행마다 1회 판정)
- **점프 리치(2.2m)보다 높이 나는 공은 스틸 불가** (로브 면역)
- 리시버 2.5m 안의 수비수는 공 궤적 위로 뛰어들어 노림 — 단 **자기 존 반경+0.8m 안에서만**

## 6. 슛 판정

- **성공률 곡선**: 0.78 − 0.05×거리(m), 하한 0.25 → 림 ~73%, 5m ~53%, 7m ~43%... 컨테스트 시 ×0.45
- **3점**: 릴리즈 지점이 림에서 6.75m 밖이면 3점, 안이면 2점
- **컨테스트 판정**: "이번 슈팅 모션 중에" 점프했고, 슈터 1.5m 안, **슈터와 림 사이(앞쪽)**에 있는 블락만 유효 → 페이크에 낚여 먼저 뛴 수비는 착지 중이라 무효
- 공 높이: 소유 중 1.2m(몸쪽) → 릴리즈 1.8m에서 출발

## 7. 블락 / 페이크

- 슈팅(또는 페이크) 모션을 본 **가장 가까운 수비중 수비수**가 1.5m 안 & 림과 슈터 사이일 때 틱당 `blockProb`(포지션별 0.25~0.5)로 점프 (1초간 이동 불가)
- 페이크(0.4초) 후 수비가 떠 있으면 즉시 진짜 슛 → 오픈 찬스. 페이크 쿨타임 2.5초

## 8. 홀더 HP — 몸통박치기

- 홀더 HP 3칸. **수비수가 드리블/드라이브 중인 홀더와 0.75m 접촉하면 박치기 모션과 함께 HP −1**, 홀더는 0.35m 넉백, 수비수는 0.35초 경직
- 수비수별 쿨타임 1초 (여러 명이 붙으면 각자 쿨타임 = 협공이 아픔)
- HP 0이 되는 박치기 = 그 수비수의 **스틸**
- HP는 공이 새 홀더에게 갈 때마다 3으로 초기화
- 박치기는 **공격 존(골대 10m 이내)에서만** — 볼 운반 구간 보호
- 홀더 대응: HP 2 → 측면 회피(전진 유지), HP 1 → 뒤로 이탈(단 프론트코트 13m 안까지만)

## 9. 수비 — 지역방어 (기본)

- **존 앵커** (2-3 / 3-2, 우하단 버튼으로 실시간 전환):
  - 2-3: 가드 위 (6.8, 5.2)/(6.8, 9.8), 아래 SF/PF/C (2.4, 3.6)/(2.4, 11.4)/(2.4, 7.5)
  - 3-2: PG 탑 (7.6, 7.5), 윙 (6.6, 3.5)/(6.6, 11.5), 빅맨 (2.3, 5.3)/(2.3, 9.7)
- 존 반경 3.8m: **존에 들어온 공격수(볼 홀더 최우선)를 존 안에서 따라붙고, 나가면 놓아준다**
- 빈 존이면 앵커를 지키며 공 쪽으로 15% 쉐이드
- 마크 추적 시 **반응 지연 0.3초** (0.3초마다만 위치 재인식 — 컷/저크가 분리를 만드는 근거)
- 항상 **마크와 림 사이**에 선다. 온볼 0.6m, 오프볼은 포지션별(C는 1.5m 드롭)
- **더블팀**: 홀더 2.5m 안에 수비 2명 → 틱당 6%로 두 번째가 존을 버리고 1.6초 협공

## 10. 오프볼 공격 무브

- 포지션별 앵커(5-아웃 변형) + 배회(0.5~2.3m, 주기 포지션별) + **V-컷 저크**(0.9m 밀착 시 2~4m 급전환)
- **스페이싱**: 3m 안 동료에게서 멀어지는 방향으로 목표 보정
- **골밑 컷**: 쿨다운(4~9초)마다 `cutChance`로 1.6초 림 파고들기
- SG는 목표가 항상 3점 라인 반경(6.9~7.6m)에 붙도록 보정
- 빅맨이 9m 밖에서 운반 중이면 가드(PG/SG)는 탑으로 올라와 받아준다

## 11. 리바운드

- 미스 → 림에서 튕겨 0.55초 포물선 낙하(림 높이에서 시작), 착지점은 림 1~3m 랜덤
- **공이 2.5m 아래로 내려오면** 0.9m 안의 선수가 **점프 캐치**(리바운드 모션 + 착지 0.5초 경직), 1.3m 안 경합자도 같이 점프
- 슛이 뜨면 양팀 PF/C는 림 앞 박스아웃 지점으로 진입
- 루즈볼 추격자는 거리 × 리바운드 가중치(C 0.7, PF 0.8, 가드 1.1~1.15)로 선정
- 공격 리바운드도 샷클락 리셋(단순화)

## 12. 득점 후 인바운드 시퀀스

1. 공이 림을 통과해 **1초간 낙하** (잡을 수 없음)
2. 림 좌측 **베이스라인 바로 밖**(코트 밖 0.35m, y=5.0)에 공 생성
3. 득점 시점에 골대와 **가장 가까웠던 새 공격팀 선수가 인바운더** (그만 픽업 가능)
4. **2순위 선수가 코트 안 4.5m 지점**에서 받을 준비
5. 인바운더가 줍고 0.3초 후 **인바운드 패스로 재개** (샷클락 리셋)
6. 그동안 나머지 8명은 존/앵커 따라 각자 진영으로 전환
- 도중 공수 전환 시 인바운드 상태 자동 무효
